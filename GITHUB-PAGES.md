# Publicação automatizada — Ciclo 07

Repositório: https://github.com/NikolasCaldeira/era-evolution

Site: https://nikolascaldeira.github.io/era-evolution/

O pipeline GitHub Actions executa `npm install`, `npm test` e `npm run build`; em caso de sucesso, publica a versão Vite compilada em GitHub Pages.

## Testes

O projeto inclui testes para navegação A*, arte, vida e UI, arsenal e escolhas de melhorias. Execute `npm test` localmente. O navegador é usado para validar o menu, movimentação, projéteis, colisões, coleta de armas e UI.

## Controles

WASD/setas — andar; Q/E — trocar arma; 1–5 — equipar; F3 — rotas; ESC — pausa; R — reinício após derrota. A cada dez eliminações surge uma relíquia. A cada dez fragmentos surgem três melhorias.
